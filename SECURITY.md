# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅        |
| < 1.0   | ❌        |

## Reporting a Vulnerability

If you find a security vulnerability in rl-lang, please report it by opening a [GitHub Issue](https://github.com/rl-lang/rl-lang/issues) or contacting a maintainer directly via GitHub.

I'll respond as soon as possible. If the vulnerability is valid I'll work on a fix and credit you in the release notes.
